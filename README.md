Cyberbullying Comment Detection

Overview:
Cyberbullying is a serious issue in online communities and social media platforms. This project aims to build a deep learning model capable of detecting Indonesian cyberbullying comments automatically based on text input.

The system classifies comments into two categories:
Cyberbullying (0)
Non-Cyberbullying (1)

This project was developed as part of a Natural Language Processing study.

Features:
- Text preprocessing for comment cleaning
- Tokenization and normalization
- Model evaluation using accuracy, precision, recall, and F1-score
- Simple prediction interface for testing comments

Tools Used:
- Python
- Transformers
- PyTorch
- Jupyter Notebook

Model Pipeline:
1. Data Collection
2. Data Cleaning
3. Text Preprocessing
5. Model Training
6. Model Evaluation
7. Prediction

Evaluation Metrics:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

This project is intended for educational and research purposes.
